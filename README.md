# Spring Boot Mockup App

A Spring Boot starter template and mockup application demonstrating best practices for Java microservice architecture.

## Tech Stack

- **Framework:** Spring Boot
- **Language:** Java
- **Build:** Maven

## Project Structure

```
src/
├── main/
│   ├── java/          # Application source code
│   └── resources/     # Configuration files
└── test/              # Unit and integration tests
```

## Getting Started

```bash
mvn clean install
mvn spring-boot:run
```
